# Winter Arc Tracker — Android App Version (PWA)

This package turns the Winter Arc Tracker into an installable Progressive Web App (PWA).

## Put it on GitHub Pages
Upload/replace these files in your existing `Winter-Arc-Tracker` repository:

- index.html
- sleep.html
- calendar.html
- review.html
- about.html
- style-v4.css
- script-v4.js
- winter-theme.png
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png
- apple-touch-icon.png

Keep the files in the repository root.

## Install on Android
1. Open your GitHub Pages Winter Arc Tracker in Chrome.
2. Wait a few seconds for it to load.
3. Open Chrome's `⋮` menu.
4. Choose **Install app** or **Add to Home screen**.
5. Confirm the name **Winter Arc Tracker**.

It will get its own icon and open in an app-like standalone window. The tracker data remains stored on the device/browser, and the service worker enables offline loading after the first successful visit.

## Important
PWA installation requires the site to be served over HTTPS. GitHub Pages provides HTTPS automatically.
